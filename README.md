# zot on Railway

zot v2.1.21, the OCI-native container registry, packaged for Railway: the official binary on Debian slim with an entrypoint that writes bcrypt htpasswd credentials from environment variables (`ZOT_ADMIN_USER`, `ZOT_ADMIN_PASSWORD`, optional `ZOT_EXTRA_USERS`) and a config with auth, access control, search and the web UI enabled.

The full template overview is published on the Railway marketplace.
